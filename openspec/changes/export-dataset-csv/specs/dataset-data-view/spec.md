# Spec Delta

## ADDED Requirements

### Requirement: 导出数据表为 CSV

数据视图 SHALL 允许用户把数值数据表导出为 CSV 文件：用户可选择导出当前页或整个数据集。导出 SHALL 只写用户指定的目标文件，不得修改源 HDF5 文件。CSV 的第一列为行号、首行列头为列号，单元格文本 SHALL 与表格显示一致。

#### Scenario: 导出当前页
- **WHEN** 用户在数值数据表选择导出当前页，并确认保存目标
- **THEN** 生成的 CSV 仅包含当前页可见的行号、列号与单元格值，行号与列号同表格一致

#### Scenario: 导出整个数据集
- **WHEN** 用户在数值数据表选择导出整个数据集，并确认保存目标
- **THEN** 系统按分块读取逐行写出数据集的全部行与列，不因数据集远大于内存而一次性载入全部元素

#### Scenario: 取消保存
- **WHEN** 用户在保存对话框中选择取消
- **THEN** 不产生 CSV 文件，当前数据表状态保持不变

#### Scenario: 导出期间读取失败
- **WHEN** 导出过程中某个数据块读取失败
- **THEN** 导出中止并通过非模态提示说明原因，源 HDF5 文件不受影响；已写出的部分文件不冒充完整导出

#### Scenario: 非数值表不提供导出
- **WHEN** 用户查看字符串数据集或复合数据集的数据表
- **THEN** 不提供 CSV 导出入口

#### Scenario: 导出完成提示与快速打开
- **WHEN** CSV 成功写入用户指定的目标文件
- **THEN** 界面显示非模态提示，给出保存路径，并提供「打开文件」与「打开文件夹」两个快捷操作
- **AND** 选择「打开文件」时用系统默认应用打开该 CSV，选择「打开文件夹」时在文件管理器中定位该 CSV 所在目录
