# Proposal

## Why

数据视图用一张自绘表格展示数据集，行号列与数据列同处一个横向滚动容器。当数据集列数较多、用户向右滚动查看远处列时，行号列会一起滚出视野，用户无法再把当前可见的数据对应到具体的行，读表与定位都变得困难。需要把行号列冻结在左侧，使其在横向滚动时始终可见。

## What Changes

- 冻结数据视图表格的首列（行号列），使其在左右横向滚动时固定在表格左侧、始终可见。
- 数据列在冻结列右侧正常横向滚动；行号列的可见性不受列分页影响。
- 纵向滚动、表头固定、翻页、坐标定位、字符串表与复合表等既有行为保持不变。
- 数值表、字符串表、复合表及读取失败占位表统一具备冻结行号列的行为（它们共用同一套表格绘制逻辑）。

## Capabilities

### New Capabilities

- （无）

### Modified Capabilities

- `dataset-data-view`：新增「行号列在横向滚动时保持可见」的行为要求。

## Impact

- 代码：`internal/view/table_view.go` 的 `dataGrid` 及其调用方（数值表、字符串表、复合表、失败占位表）。
- 依赖：`github.com/egoist/mygo/ui` 的滚动与 sticky 定位能力；需在实现时确认其对「左向固定」的支持方式。
- 测试：`internal/view/table_test.go` 需补充冻结列行为的验证。
- API / 数据格式：无变化。
