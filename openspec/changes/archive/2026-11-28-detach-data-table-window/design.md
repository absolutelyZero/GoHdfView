# Design

## Context

数据视图由 view.DataTable(c, app) 绘制，读取通过 view.App 的 Reader/Meta（通常来自当前 *hdf5.Document）完成。主窗口 app 持有文件集合与选中状态。MyGo 支持多原生窗口：mygo.NewWindow(WindowOptions{Content: ui.View(...)})、Show()、Close()。动机与范围见 proposal.md，行为见 specs delta。本变更与 open-multiple-files（统一对象树）相互独立，不依赖其交互模型。

## Goals / Non-Goals

**Goals:**
- 把当前数据集的数据表放到独立原生窗口，多个窗口可并存对比。
- 窗口内容在打开时固定；每个窗口的分页/视图状态独立。
- 窗口生命周期清晰，退出时不遗留孤立窗口。

**Non-Goals:**
- 不在独立窗口提供数据编辑（保持只读）。
- 不实现独立窗口与主窗口的选中联动（内容打开即固定，是明确需求）。
- 不依赖 open-multiple-files 的统一树模型。

## Decisions

1. **每窗口一个独立 view.App。** 打开独立窗口时新建 view.App，通过 SetDocument 复用当前文件句柄、用 SelectPath 定位到打开时选中的数据集节点，并注入与主窗口相同的 Reader/Meta（同一个文档来源，只读共享句柄，不重复打开 HDF5 文件）。理由：独立的分页/视图/表格状态来自各自 App，天然互不干扰；共享文档句柄避免重复 I/O 与重复占用。
2. **内容快照固定。** 独立窗口创建后其 view.App 不再随主窗口选中变化而更新；DataTable 每帧从该窗口自己的 App 取状态。理由：满足“打开时固定”的需求，主窗口切换节点不影响已打开的窗口。
3. **窗口集合由 main 管理。** app 新增 windows []*tableWindow，其中 tableWindow{win *mygo.Window; state *view.App}；打开时创建 App → 装配回调 → NewWindow（标题含数据集名与文件名）→ Show() → 加入集合；关闭时从集合移除并释放。理由：集中管理便于统一清理。
4. **入口。** 数据视图工具栏增加「独立窗口」按钮，并在「视图」菜单/系统菜单增加「在独立窗口打开数据表」项，共用同一操作函数 openTableInWindow()；仅当选中项是可显示的数据集时可用。理由：按钮贴近数据、菜单提供快捷键一致性。备选（仅菜单）发现性差，不采用。
5. **生命周期与清理。** 独立窗口自身的关闭按钮/系统关闭事件从集合移除该窗口（不关闭共享文档句柄，因为主窗口仍持有）；主窗口 OnClose 遍历集合逐个 Close()。理由：文档句柄归主窗口所有，独立窗口只是只读视图，避免提前释放导致主窗口失效。
6. **回调装配。** 每个独立 App 注入 SetAsync/SetInvalidate（重绘指向自己的窗口，捕获窗口指针做身份比较），CSV 导出入口在独立窗口可复用（指向其自己的数据集）。理由：与多窗口异步读取一致，避免结果画到错误窗口。
7. **测试策略。** 窗口创建/关闭逻辑通过可注入的窗口工厂测试（假工厂记录创建/关闭次数与标题），数据表内容复用现有 view.DataTable 的 Tester 测试；不依赖真实原生窗口。理由：CI 无窗口环境仍可验证生命周期与入口。
8. **主题与背景一致性。** 独立窗口的 content 闭包在每次绘制前调用 `c.SetTheme(view.Theme())`，并以 `ui.Column(c)` + `Background(view.ColBg)` 包裹 `view.DataTable(c, st)`，与主窗口 `view()` 的装配保持一致；主题在每帧设置以支持主题切换。理由：当前闭包直接调用 `view.DataTable(c, st)` 未设置主题，导致独立窗口以默认浅色主题渲染，与主窗口深色风格不协调。

## Risks / Trade-offs

- [多窗口共享文档句柄] → 句柄归主窗口所有，独立窗口只读复用；主窗口退出统一关闭，避免悬空或重复释放。
- [异步读取画到错误窗口] → 决策 6 的窗口指针身份比较，确保重绘只作用于自己的窗口。
- [窗口数过多占资源] → 每窗口只有一份轻量 view.App 与表格控件，数据按页读取；由用户显式打开控制数量。
- [独立窗口与主窗口状态不一致] → 内容固定是明确需求，非缺陷；窗口标题标明数据集以免混淆。

## Migration Plan

无磁盘数据迁移：新增功能；关闭所有独立窗口后不影响既有主窗口行为。
