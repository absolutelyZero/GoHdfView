# Proposal

## Why

当前数据表只能显示在主窗口右侧的工作区内，一次只能看一个选中数据集。对比两个数据集时，用户只能反复切换选中节点，无法并排查看：切换后前一张表就消失了。物理/实验数据核对常需要在两个表之间来回对照数值、确认差异，单工作区是明显瓶颈。MyGo 支持创建多个原生窗口（`NewWindow`/`Show`/`Close`），可以把数据表独立成窗口，桌面窗口管理器即可并排、分屏摆放多个表，天然适合多窗口对比。

## What Changes

- 数据视图提供「独立窗口打开数据表」入口（按钮 + 菜单项），把当前选中数据集的数据表拉到一个新的原生窗口。
- 每个独立窗口持有自己的数据表状态（数据集、分页、视图模式），互不干扰；可同时打开多个独立窗口并排对比。
- 独立窗口一旦打开，其内容固定为打开时选中的数据集；主窗口随后切换选中节点不影响已打开的独立窗口。
- 独立窗口是只读的数据表视图，沿用同一套表格渲染与数值格式化；窗口标题显示数据集与文件名。
- 关闭独立窗口只释放该窗口与其资源，不影响主窗口与其它独立窗口；主窗口关闭时所有独立窗口一并关闭。
- 保留只读约束：独立窗口不修改任何 HDF5 源文件。
- 独立窗口沿用主窗口的深色主题与背景，表格、工具栏与分页条的视觉风格与主窗口一致。

## Capabilities

### New Capabilities

- `detached-table-window`: 数据表的独立窗口能力——打开、多窗口并存、内容固定、生命周期与只读约束。

### Modified Capabilities

- viewer-shell: 在「视图切换」相关需求中增加“把数据表在独立窗口打开”的入口，菜单与快捷键与主视图保持一致。

## Impact

- main.go: 管理独立窗口集合（创建、显示、关闭、主窗口退出时统一释放）；「独立窗口打开数据表」入口与 `mygo.NewWindow` 装配。
- internal/view: `DataTable(c, app)` 已可直接复用；独立窗口持有自己的 `view.App`（数据集与分页状态独立），Reader/Meta 复用当前文档来源。
- 无新增第三方依赖；沿用 MyGo 原生窗口与现有表格渲染。
- 与 `open-multiple-files`（统一对象树）相互独立：本变更只负责“把表拉成独立窗口”，不依赖其交互模型。
