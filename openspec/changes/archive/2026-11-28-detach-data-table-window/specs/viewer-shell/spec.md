# Spec Delta

## MODIFIED Requirements

### Requirement: 视图切换

右侧工作区 SHALL 提供「数据」「元数据」「属性」三个视图，用户可在其间切换，当前视图在切换对象后保持。数据视图 SHALL 提供把数据表在独立窗口打开的入口。

#### Scenario: 切换到元数据视图
- **WHEN** 用户在数据视图下点击「元数据」标签
- **THEN** 右侧显示元数据视图，再次选中其他数据集时仍显示元数据视图

#### Scenario: 选中不支持数据的对象
- **WHEN** 用户选中一个组
- **THEN** 「数据」标签不可用并置灰，当前视图自动落到「元数据」

#### Scenario: 从数据视图打开独立窗口
- **WHEN** 用户选中一个数值数据集并在数据视图下选择「独立窗口打开」
- **THEN** 该数据集的数据表在新的原生窗口中打开，主窗口视图保持不变
