# Design

## Context

侧栏对象树由 `internal/view/tree.go` 的 `Tree` 用 mygo 的 `ui.Outline` 绘制：行高由行前缀里的 26px 占位 Box（`tree.go:64`）撑起，行内依次是展开箭头（11×11）、类型图标（`kindIcon`，12×12）、名称（12.5）与维度概要（10.5）、链接标注（11）。选中行的底色不由应用层绘制，而是 mygo `List` 在内部调用 `node.Selected(on)` 时取主题强调色：`style.go:55` 将 `t.Accent` 设为 `ColSel`（`#1B2024`）。

约束：

- 全应用只有对象树这一个可选中的 `ui.List`；属性列表、表格数据视图都是普通 Column/绘制，不消费 `t.Accent`。
- 代码注释以 `ui/ui.pen` 设计稿为视觉依据，但设计稿与代码本就存在偏差（概要字号 9.5 vs 代码 10.5），本次以代码为最终实现事实。
- `ui/ui.pen` 不参与构建（无代码生成），是 pen.dev 中维护的设计文档。

## Goals / Non-Goals

**Goals:**

- 树行整体增大一号：箭头、类型图标、名称、维度概要、链接标注各增大约 1px，行高随之增至 28px。
- 选中行按设计稿高亮：底色 `#191E22`、类型图标琥珀色 `ColAccent`、名称亮色加粗、维度概要暖灰 `#8A7B5A`、箭头变亮。
- 改动集中在 `tree.go` 与 `style.go`，不触碰树的数据流与选中逻辑（`TreeRow`、`treeSelID`、`syncRow` 等）。

**Non-Goals:**

- 不改侧栏筛选框、表格数据视图、面包屑、属性列表等其他界面的字号或样式。
- 不改 `t.Selection`（文本选区）与 `t.Focus`（焦点环）等其余主题色。
- 不手工修改 `ui/ui.pen` 设计稿 JSON；如需同步设计稿在 pen.dev 中另行调整。

## Decisions

### D1. 选中底色走主题强调色，而不是应用层自绘

把 `style.go` 中的选中底色常量改为设计稿的 `#191E22`（重命名 `ColSel` → `ColSelRow`），仍赋给 `t.Accent`，让 mygo `List` 内部继续画选中底色。

- 理由：mygo `node.Selected(on)` 是唯一画行底色的入口，应用层的行前缀/行内容回调只能往行里追加子元素，无法可靠地铺满整行背景（前缀缩进区在内容回调之外）。
- 备选方案：在行内容里叠一层背景元素——只能覆盖内容起点之后的区域，缩进区留白，效果不完整；用 Painter 自绘钩子侵入 mygo 内部，成本高。已确认全应用只有树消费 `t.Accent`（无 ComboBox/Checkbox/Tabs），改主题色无外溢。

### D2. 「一号」的具体数值

- 展开箭头 11×11 → 12×12（含叶子节点占位 Box 11 → 12）
- 类型图标 12×12 → 13×13
- 名称字号 12.5 → 13.5
- 维度概要字号 10.5 → 11.5
- 链接标注字号 11 → 12
- 行高 26 → 28（13.5 的名称加图标 13 后仍留 7px 上下余量）

箭头与类型图标的增量恰好与设计稿一致（12 / 13）；文字在现状基础上 +1。缩进与间距（首层 10px、每层 15px、间隙 6px、行尾 10px）不变。

### D3. 选中态的图标与文字取色

- 类型图标：`pick(on, ColAccent, ColMute)`——选中变琥珀 `#E0A64A`（设计稿选中行的图标即此色）。
- 名称：字号 13.5，`pick(on, ColText, ColName)` 不变；选中时加 `FontWeight(500)`（设计稿 medium）。
- 维度概要：选中时 `#8A7B5A`（设计稿选中行概要色），未选中仍 `ColMute`；链接标注保持 `ColMute`。
- 展开箭头：沿用现有 `pick(on, ColText, ColMute)`。

### D4. 行高断言随行高更新

`tree_test.go` 的 `TestTreeRowHeight` 现断言 26px（容差 ±1），改为 28px（容差 ±1）；另补一条选中行高亮的断言（见 tasks），用测试器的元素查找验证选中行的样式生效。

## Risks / Trade-offs

- [改 `t.Accent` 影响面] → 已核实唯一消费者是树的 `List`；若未来引入 mygo 自带 ComboBox 等控件，其选中底色会随之变为 `#191E22`，届时再按控件拆分主题。
- [行高增大减少可视行数] → 28px 下每屏约少 2 行，可接受；不引入密度切换。
- [13.5 非整数磅值] → 渲染器按浮点字号处理，现有 12.5/10.5 已在用，风险与现状一致。
- [设计稿与代码继续分叉] → 记录在 proposal Impact；设计稿同步留给 pen.dev 手工维护。

## Migration Plan

纯界面改动，无数据迁移。回滚即还原 `tree.go` 与 `style.go` 的两处提交。
