# Proposal

## Why

侧栏对象树的行内元素整体偏小（名称 12.5px、类型图标 12px、展开箭头 11px、维度概要 10.5px），长时间浏览不易辨认；同时选中行目前只靠主题强调色 `#1B2024` 的一层淡底色区分，与侧栏底色 `#101316` 几乎无法分辨，用户难以确认当前正在查看哪个对象。

## What Changes

- 行内图标与文字增大一号：
  - 展开箭头图标 11×11 → 12×12
  - 类型图标（folder / table-2 / image / type / link）12×12 → 13×13
  - 名称字号 12.5 → 13.5
  - 维度概要字号 10.5 → 11.5
  - 链接标注字号 11 → 12
- 行高随内容从 26px 增至 28px；缩进与间距规则不变（首层 10px、每层 15px、图标间隙 6px、行尾 10px）
- 选中行按 `ui/ui.pen` 设计稿高亮，替代目前几乎不可见的淡底色：
  - 行底色提亮为 `#191E22`
  - 类型图标变为琥珀色 `#E0A64A`（ColAccent）
  - 名称变亮为 `#E7EAED` 并加粗（medium）
  - 展开箭头同步变亮
- 范围仅限侧栏对象树的行展示；侧栏筛选框、表格数据视图、面包屑等其余界面不变

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `object-tree`：「树行的排版与缩进」要求中的行高、图标与字号数值更新；新增「选中行高亮」要求，规定选中行的底色、图标与文字样式。

## Impact

- 代码：`internal/view/tree.go`（行高占位 Box、箭头/类型图标尺寸、行文字字号、选中态取色）；`internal/view/style.go`（新增选中行颜色常量，如 ColSelRow = `#191E22`；主题强调色 `t.Accent = ColSel` 保持不变，避免影响表格等其他列表控件的选中样式）
- 测试：`internal/view/tree_test.go` 的 `TestTreeRowHeight` 断言行高 26px，需随行高改为 28px；可能需补充选中行高亮的断言
- 设计稿：`ui/ui.pen` 的 tree-row 与代码实现本就存在偏差（如概要字号 9.5 vs 代码 10.5），本次不手工修改设计稿 JSON，以代码为最终实现事实；如需同步可在 pen.dev 中另行调整
