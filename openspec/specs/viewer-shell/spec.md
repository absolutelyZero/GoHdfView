# viewer-shell Specification

## Purpose

定义桌面应用的对外形态：窗口与菜单、文件打开与拖放、左右分栏布局与状态栏、视图切换、快捷键与错误提示，让阅读器在 Windows 上像一个原生工具那样可用。

## Requirements

### Requirement: 主窗口与分栏布局

应用 SHALL 在一个主窗口内提供左右分栏：左侧为对象树，右侧为工作区，底部为状态栏。

#### Scenario: 启动应用
- **WHEN** 用户启动应用且没有指定文件
- **THEN** 主窗口显示空状态，提示「打开 HDF5 文件或把文件拖入窗口」

#### Scenario: 调整分栏宽度
- **WHEN** 用户拖动左右分栏之间的分隔条
- **THEN** 两栏宽度随之变化，右侧工作区随之重排

#### Scenario: 状态栏信息
- **WHEN** 已打开一个文件并选中一个数据集
- **THEN** 状态栏显示文件名、当前对象完整路径与其元素总数

### Requirement: 打开文件的方式

用户 SHALL 能通过菜单、快捷键与拖放三种方式打开文件。

#### Scenario: 菜单打开
- **WHEN** 用户从「文件」菜单选择「打开…」
- **THEN** 应用弹出系统文件选择对话框，过滤器默认只显示 `.h5`、`.hdf5`、`.he5`、`.mat`

#### Scenario: 快捷键打开
- **WHEN** 用户按下 Ctrl+O
- **THEN** 应用弹出与菜单相同的文件选择对话框

#### Scenario: 拖放打开
- **WHEN** 用户把一个 HDF5 文件拖入窗口
- **THEN** 应用打开该文件，效果与通过菜单选择相同

#### Scenario: 命令行参数
- **WHEN** 用户以 `GoHdfView.exe path\to\file.h5` 启动应用
- **THEN** 应用启动后直接打开该文件

### Requirement: 视图切换

右侧工作区 SHALL 提供「数据」「元数据」「属性」三个视图，用户可在其间切换，当前视图在切换对象后保持。

#### Scenario: 切换到元数据视图
- **WHEN** 用户在数据视图下点击「元数据」标签
- **THEN** 右侧显示元数据视图，再次选中其他数据集时仍显示元数据视图

#### Scenario: 选中不支持数据的对象
- **WHEN** 用户选中一个组
- **THEN** 「数据」标签不可用并置灰，当前视图自动落到「元数据」

### Requirement: 菜单与快捷键

应用 SHALL 提供「文件」「视图」「帮助」三个菜单，并为常用操作提供快捷键。

#### Scenario: 关闭文件
- **WHEN** 用户从「文件」菜单选择「关闭文件」或按 Ctrl+W
- **THEN** 应用释放文件句柄，界面回到空状态

#### Scenario: 全部展开
- **WHEN** 用户从「视图」菜单选择「全部展开」或按 Ctrl+Shift+E
- **THEN** 对象树全部展开

#### Scenario: 关于
- **WHEN** 用户从「帮助」菜单选择「关于」
- **THEN** 应用显示版本号与所用 HDF5 解析库的版本

### Requirement: 错误提示不阻塞浏览

错误提示 SHALL 以非模态方式呈现，不得因为一次读取失败而阻止用户继续浏览其他对象。

#### Scenario: 数据集读取失败后继续浏览
- **WHEN** 某个数据集读取失败并显示错误提示
- **THEN** 用户仍可在对象树中选中其他数据集并正常查看，提示可被关闭

#### Scenario: 打开损坏文件失败后保留原状态
- **WHEN** 用户尝试打开一个损坏文件而当前已有打开的文件
- **THEN** 应用显示错误，当前文件与其视图保持原状

### Requirement: Windows 上的自定义标题栏

应用在 Windows 上 SHALL 隐藏系统标题栏，由应用顶栏同时充当标题栏：顶栏沿用应用深色配色，保留系统的最小化、最大化与关闭按钮，并让顶栏内容避开这些按钮。

#### Scenario: 系统为浅色模式

- **WHEN** Windows 使用浅色外观时启动应用
- **THEN** 窗口顶部不出现浅色系统标题栏，顶栏保持应用的深色配色

#### Scenario: 拖动标题栏

- **WHEN** 用户在顶栏空白处按住并拖动
- **THEN** 窗口随指针移动

#### Scenario: 双击标题栏

- **WHEN** 用户双击顶栏空白处
- **THEN** 窗口在最大化与还原之间切换，与系统标题栏的双击行为一致

#### Scenario: 窗口按钮不遮挡顶栏操作

- **WHEN** 窗口缩到允许的最小宽度
- **THEN** 顶栏右侧的操作按钮完整可见，且不与系统窗口按钮重叠

#### Scenario: 非 Windows 平台

- **WHEN** 应用在 macOS 或 Linux 上运行
- **THEN** 保留系统标题栏，顶栏不额外为窗口按钮预留空间
